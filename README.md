# PornzHub

PornzHub is an adult video discovery and streaming website focused on embedded content, localized pages, SEO-friendly video catalogs, blogs, and an optional live-cam section.

Website: https://pornzhub.com/

This public repository is a presentation page only. Production source code, operational configuration, user data, media, and credentials are intentionally kept in the private repository and on the production infrastructure.

## Main capabilities

- Adult video catalog and category navigation
- Embedded third-party video discovery
- Multilingual routes and localized content
- SEO metadata, canonical URLs, hreflang, sitemap generation, and Open Graph images
- Blog and editorial content
- Optional live-cam directory and embedded experience
- Responsive dark-red frontend theme
